# M3 — Editorial index

M3 derives a source-scoped editorial index from validated M2 extraction records. It does not call a model, rewrite original stories, merge people across sources, or publish content.

## Records

- `projects`: project/product mentions with story-local evidence.
- `facts`: typed facts with verbatim English evidence and active/inactive state.
- `editorial_candidates`: one explainable editorial score and human review state per story.
- `person_profiles` and `case_index`: read-only views over source-scoped records.

## Scoring

The score estimates editorial usefulness, not truthfulness, revenue verification, or investment quality. The component rules are implemented in `src/overseas_stories/editorial.py`.

## Safety

- Each evidence string must be an exact substring of the source story.
- Same-name entities from different sources are not automatically merged.
- Re-indexing is deterministic and preserves human review status.
- Only the private runner role can access these tables.
